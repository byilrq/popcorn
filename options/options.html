Popcorn

独立扩展设置页。保存后刷新目标 PT 页面即可生效。

转发站点设置

和原“脚本设置 → 转发站点设置”一致。可以取消勾选来临时禁用；也可以点“删除选中”把不常用小站从设置页里隐藏。删除只是隐藏，点“恢复已删除站点”可找回。

当前快捷搜索列表

这里控制种子页面显示的“快速搜索”站点。默认：PTP / BHD / CHD / ADE / GPW / BTN / 豆瓣。点“移除”可删除；也可以从内置网站库添加其他站点。

剧集搜索 IMDb 归一化站点

仅这里勾选的快速搜索站点，会在“豆瓣剧集/季/单集页面”点击搜索时，把豆瓣当前季/单集 IMDb 转成剧集主 IMDb 后再检索。电影页面不处理。默认勾选 BHD / BTN；CHD、ADE 或你手动添加的站点，可在这里自行勾选。

从内置网站库添加

输入站点名搜索并新增。下面的高级编辑区每行一个链接，支持原脚本里的 {imdbid} / {imdbno} / {search_name} 占位符。

手动添加到当前快捷搜索

可手动添加站点名和搜索网址；网址支持 {imdbid} / {imdbno} / {search_name}。添加后会加入当前快捷搜索列表，并保存在你的自定义库中。

签到 / 登录保活

这里做扩展版的基础保活：浏览器启动后会自动后台访问你添加的站点首页，尽量刷新登录状态。每个站点最近 7 天内成功访问过就不会重复自动访问；超过 7 天后才会再次保活。遇到验证码、二次验证或站点强制登录时，仍需要你手动处理。

暗色背景网站

这里的站点明细由“当前快捷搜索列表”自动同步。默认勾选 BHD；如果 BHD 手动切回亮色皮肤，可以在这里取消勾选。之后你添加到快捷搜索列表的站点，也会出现在这里，可自行勾选为暗色背景样式。
